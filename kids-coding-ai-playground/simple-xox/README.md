# Simple XOX

A two-player Tic-Tac-Toe game written with basic Python. Player X and Player O take turns choosing a numbered square. The game checks for a win or a draw.

## Run

Open a terminal in this folder and run:

```text
python main.py
```

No extra packages are needed. The board positions are numbered like this:

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```

The source introduces lists, loops, functions, input, conditions, and checking winning combinations.
